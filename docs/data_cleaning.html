Limpieza y Preparación de Datos

ENEMDU — Encuesta Nacional de Empleo, Desempleo y Subempleo | Enero 2026

Introducción

Este documento registra el proceso de limpieza y preparación de los datos provenientes de la ENEMDU (Encuesta Nacional de Empleo, Desempleo y Subempleo) del período enero 2026, publicada por el INEC. El objetivo es transformar el archivo fuente en formato .sav (SPSS) en un dataset estructurado y limpio, listo para el análisis visual.

El flujo de ejecución sigue este orden estricto para evitar errores de columna no encontrada:

  1. Carga del archivo fuente
  2. Exploración inicial sobre los datos crudos
  3. Recodificación de condact (base de todas las variables derivadas)
  4. Construcción de horas trabajadas totales
  5. Manejo de valores faltantes (sobre columnas ya existentes)
  6. Mapeo de ciudades y etnia
  7. Selección final, renombrado y exportación

Recodificación de condact

La variable condact llega como texto etiquetado desde el .sav. Se mapea a la escala numérica oficial del INEC antes de cualquier otra transformación, ya que varias variables dependen de ella.

Mostrar código 
# Mapeo de etiquetas de texto a códigos numéricos oficiales INEC
# Fuente: https://anda.inec.gob.ec/anda/index.php/catalog/1048/datafile/F17/V1815
mapa_condact = {
    "Empleo Adecuado/Pleno": 1,
    "Subempleo por insuficiencia de tiempo de trabajo": 2,
    "Subempleo por insuficiencia de ingresos": 3,
    "Otro empleo no pleno": 4,
    "Empleo no remunerado": 5,
    "Empleo no clasificado": 6,
    "Desempleo abierto": 7,
    "Desempleo oculto": 8,
    "Población Económicamente Inactiva": 9
}

df["condact"] = df["condact"].map(mapa_condact)

# Menores de 15 años reciben código 0: quedan fuera de la PET
# p03 viene como string tras el strip global -> convertir a numérico primero
df["p03"] = pd.to_numeric(df["p03"], errors='coerce')
df.loc[df['p03'] < 15, 'condact'] = 0

print("Distribución de condact tras recodificación:")
print(df["condact"].value_counts())

Construcción de Horas Trabajadas Totales

El archivo fuente no incluye una variable de horas totales precalculada. Se construye sumando las horas del empleo principal (p51a) y del empleo secundario (p51b), que son las únicas columnas con valores numéricos de horas en el cuestionario.

Mostrar código 
# Convertir a numérico (vienen como Categorical desde el .sav)
df['p51a'] = pd.to_numeric(df['p51a'], errors='coerce')  # horas empleo principal
df['p51b'] = pd.to_numeric(df['p51b'], errors='coerce')  # horas empleo secundario

# Horas totales = suma de ambos empleos (NaN si no trabaja en ninguno)
df['horas_trabajo_totales'] = df['p51a'].add(df['p51b'], fill_value=0)
df.loc[df['p51a'].isna() & df['p51b'].isna(), 'horas_trabajo_totales'] = np.nan

# Versión para visualización: 0 en lugar de NaN (inactivos y desempleados)
df['horas_visual'] = df['horas_trabajo_totales'].fillna(0)

print("Distribución de horas totales trabajadas:")
print(df['horas_trabajo_totales'].describe())

Manejo de Valores Faltantes

Esta sección opera sobre columnas que ya existen en el dataframe. Ejecutarla antes de la recodificación y construcción de variables causaría KeyError.

La ENEMDU tiene diseño de cuestionario condicional: preguntas sobre búsqueda de empleo solo se hacen a desempleados, preguntas laborales solo a ocupados, etc. Los NaN en esas variables son ausencias estructurales por diseño, no errores de medición.

Variables categóricas: NaN → "No hay dato"

Mostrar código 
# p06 = estado_civil | p07 = asiste_a_clases
# Estas columnas son Categorical, por lo que se convierte a str antes de rellenar.
cols_cat = ['p06', 'p07']
for col in cols_cat:
    df[col] = df[col].astype(str).replace('nan', 'No hay dato')

Justificación: Las columnas Categorical de SPSS no admiten valores nuevos sin registrarlos primero como categoría válida. Convertir a str resuelve esto y produce una columna de texto directamente usable en gráficos. El valor 'nan' que genera .astype(str) se reemplaza por la etiqueta 'No hay dato' para claridad visual.

Construcción de adec (empleo adecuado)

Mostrar código 
# adec no viene precalculada en el archivo; se deriva de condact
# condact == 1 corresponde a Empleo Adecuado/Pleno
df['adec'] = np.where(df['condact'] == 1, 1.0, np.nan)

Justificación: A diferencia de empleo y desempleo, la variable adec no viene en el archivo fuente. Se construye desde condact ya recodificado: código 1 = Empleo Adecuado/Pleno. Se usa np.nan en lugar de 0 para ser consistente con la convención de indicadores del INEC.

Mapeo de etnia

Mostrar código 
# La etnia está en p15 (autoidentificación étnica)
mapping_etnia = {
    1: 'Mestizo',
    2: 'Indígena',
    3: 'Afro/Negro',
    4: 'Mulato',
    5: 'Blanco',
    6: 'Otros'
}
df['etnia_nombre'] = pd.to_numeric(df['p15'], errors='coerce') \
                       .map(mapping_etnia).fillna('No hay dato')

Justificación: La variable de autoidentificación étnica se encuentra en p15, no en una columna llamada etnia. Se convierte a numérico primero porque viene como Categorical desde el .sav, y se rellena con 'No hay dato' para no excluir registros.

Exportación del Dataset Limpio

Mostrar código 
cols_numericas = [
    'edad', 'personas_hogar', 'nivel_educativo',
    'condicion_actividad', 'empleo_adecuado', 'desempleado',
    'horas_trabajo_totales', 'horas_visual',
    'ingreso_laboral', 'ingreso_per_capita'
]
for col in cols_numericas:
    if col in df_final.columns:
        df_final[col] = pd.to_numeric(df_final[col], errors='coerce')

# area viene como Categorical texto ('Urbana'/'Rural') -> convertir a código numérico
if 'area' in df_final.columns:
    df_final['area'] = df_final['area'].astype(str).map(
        {'Urbana': 1, 'Rural': 2, '1.0': 1, '2.0': 2, '1': 1, '2': 2}
    )

# genero y seguro pueden venir como Categorical -> numérico
for col in ['genero', 'seguro']:
    if col in df_final.columns:
        df_final[col] = pd.to_numeric(df_final[col], errors='coerce')

# empleo y desempleado vienen como texto etiquetado desde el .sav
# los convertimos a 1.0/NaN para que sean usables como indicadores
if 'empleo' in df_final.columns:
    df_final['empleo'] = df_final['empleo'].map(
        lambda x: 1.0 if str(x).strip() in ['Población con empleo', '1.0', '1'] else float('nan')
    )
if 'desempleado' in df_final.columns:
    df_final['desempleado'] = df_final['desempleado'].map(
        lambda x: 1.0 if str(x).strip() in ['Población con desempleo', '1.0', '1'] else float('nan')
    )

df_final.to_csv('SPSS/ENEMDU_clean.csv', index=False)
print('Dataset exportado exitosamente → SPSS/ENEMDU_clean.csv')
print(df_final[['area','genero','nivel_educativo','ingreso_laboral','empleo_adecuado']].dtypes)
