Limpieza y Preparación de Datos

ENEMDU — Encuesta Nacional de Empleo, Desempleo y Subempleo | Enero 2026

Introducción

Este documento registra el proceso de limpieza y preparación de los datos provenientes de la ENEMDU (Encuesta Nacional de Empleo, Desempleo y Subempleo) del período enero 2026, publicada por el INEC. El objetivo es transformar el archivo fuente en formato .sav (SPSS) en un dataset estructurado y limpio, listo para el análisis visual.

El flujo de ejecución sigue este orden estricto para evitar errores de columna no encontrada:

  1. Carga del archivo fuente
  2. Exploración inicial sobre los datos crudos
  3. Recodificación de condact (base de todas las variables derivadas)
  4. Construcción de horas trabajadas totales
  5. Manejo de valores faltantes (sobre columnas ya existentes)
  6. Mapeo de ciudades y etnia
  7. Selección final, renombrado y exportación

Carga del Dataset

Librerías necesarias

Mostrar código 
import pandas as pd
import numpy as np

Justificación: pandas maneja la lectura del .sav y todas las transformaciones tabulares. numpy permite operaciones vectorizadas eficientes equivalentes al RECODE y COMPUTE de SPSS.

Lectura del archivo SPSS

Mostrar código 
file_path = 'SPSS/enemdu_persona_2026_01.sav'
df = pd.read_spss(file_path)

print(f"Filas cargadas:       {df.shape[0]:,}")
print(f"Columnas disponibles: {df.shape[1]}")


for col in df.select_dtypes(['category', 'object']).columns:
    try:
        df[col] = df[col].astype(str).str.strip()
        df[col] = df[col].replace('nan', float('nan'))
    except Exception:
        pass

# ── Mapear columnas Categorical clave a numérico ─────────────────

# area: Urbana/Rural -> 1/2
df['area'] = df['area'].map({'Urbana': 1, 'Rural': 2})
print("Area:", df['area'].value_counts().to_dict())

# p10a: nivel educativo -> escala numérica ordinal
mapa_p10a = {
    'Ninguno': 1,
    'Centro de alfabetización': 2,
    'Jardín de infantes': 3,
    'Primaria': 4,
    'Educación Básica': 5,
    'Secundaria': 6,
    'Educación  Media': 7,
    'Educación Media': 7,
    'Superior no universitario': 8,
    'Superior Universitario': 9,
    'Post-grado': 10
}
df['p10a'] = df['p10a'].map(mapa_p10a)
print("Nivel educativo:", df['p10a'].value_counts().to_dict())

# p02: género -> 1=Hombre, 2=Mujer
df['p02'] = df['p02'].map({'Hombre': 1, 'Mujer': 2})

# p05b: seguro -> numérico si viene como texto
mapa_seguro = {
    'IESS, seguro general': 1,
    'IESS, seguro voluntario': 2,
    'IESS, seguro campesino': 3,
    'Es jubilado del IESS/ISSFA/ISSPOL': 4,
    'Issfa o Isspol': 4,
    'Seguro privado': 5,
    'Ninguno': 6,
    'No sabe': 7
}
df['p05b'] = df['p05b'].map(mapa_seguro).fillna(
    pd.to_numeric(df['p05b'], errors='coerce')
)

En esta versión de la ENEMDU, variables como condact vienen como texto etiquetado y deben recodificarse antes de usarse analíticamente.

Manejo de Valores Faltantes

Esta sección opera sobre columnas que ya existen en el dataframe. Ejecutarla antes de la recodificación y construcción de variables causaría KeyError.

La ENEMDU tiene diseño de cuestionario condicional: preguntas sobre búsqueda de empleo solo se hacen a desempleados, preguntas laborales solo a ocupados, etc. Los NaN en esas variables son ausencias estructurales por diseño, no errores de medición.

Variables categóricas: NaN → "No hay dato"

Mostrar código 
# p06 = estado_civil | p07 = asiste_a_clases
# Estas columnas son Categorical, por lo que se convierte a str antes de rellenar.
cols_cat = ['p06', 'p07']
for col in cols_cat:
    df[col] = df[col].astype(str).replace('nan', 'No hay dato')

Justificación: Las columnas Categorical de SPSS no admiten valores nuevos sin registrarlos primero como categoría válida. Convertir a str resuelve esto y produce una columna de texto directamente usable en gráficos. El valor 'nan' que genera .astype(str) se reemplaza por la etiqueta 'No hay dato' para claridad visual.

]

# area viene como Categorical texto ('Urbana'/'Rural') -> convertir a código numérico
if 'area' in df_final.columns:
    df_final['area'] = df_final['area'].astype(str).map(
        {'Urbana': 1, 'Rural': 2, '1.0': 1, '2.0': 2, '1': 1, '2': 2}
    )

# genero y seguro pueden venir como Categorical -> numérico
for col in ['genero', 'seguro']:
    if col in df_final.columns:
        df_final[col] = pd.to_numeric(df_final[col], errors='coerce')

    )
